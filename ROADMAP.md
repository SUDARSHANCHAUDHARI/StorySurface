# StorySurface Roadmap

## Current Direction

StorySurface should evolve into an interactive narrative interface where story structure, tone, and presentation move together.

## Near-Term Improvements

- refine reading rhythm and spacing
- strengthen scene contrast by tone
- improve branching button clarity
- add more visual polish to the stage layout
- improve mobile reading comfort

## Next Features

- richer generated story structures
- more branching outcomes
- scene recap or chapter rail
- typewriter or staggered text reveal
- alternate tone styles per story

## Add-Ons

- ambient sound hooks
- image or illustration slots per scene
- creator presets by genre
- exportable story share cards
- optional voiceover scaffolding

## Good To Have

- reading mode vs creator mode
- undo / revisit previous choices
- scene bookmarking
- presentation mode for storytelling demos
- lightweight story analytics later

## Production Readiness Later

- prompt safety and moderation layer
- persistence for saved stories
- environment config and model wiring
- share link handling
- deployment config and domain setup
